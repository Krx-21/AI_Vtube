# C05-stt-audio — STT, turn-taking, collab audio, voice-chat channel
Verdict counts: {'confirmed': 3, 'disputed': 2, 'meta': 2, 'unverifiable': 2, 'likely': 5}

## Summary A (evidence hunter)
Only two things in this cluster are established at primary-source tier, and both come from documents Vedal wrote himself. First, the decision loop is serial: in VedalAI/neuro-sdk discussion #58 (22 Feb 2025) Vedal states that "she can only process one thing at once" and that context arriving mid-decision "will be merged after she is finished making her decision" — his separate remark about two simultaneous action/forces being processed in parallel and merged is explicitly flagged "untested" design intent, so the two statements are not in conflict once you see that one describes thinking and the other describes system-level handling. Second, the in-game voice path is fully specified in API/VOICE_CHAT.md, a file committed by Vedal987 on 19 Aug 2026 (SHA 6b79780): the game must tap each remote player's stream before mixing, register speakers as {id: uint16, name: string} where "name is what speech-to-text attribution uses", and send 48 kHz mono Float32 little-endian PCM with a 4-byte header carrying the speaker id (20 ms frames recommended, up to 32 concurrent speakers) — so who-said-what is supplied by the game, never inferred by diarization, and STT runs server-side on Neuro's own backend ("server ──► STT (attributed) ──► Neuro"), with her TTS returned as PCM for the game to inject into its voice-transmit path or a virtual microphone. That same T1 document gives the only 2026-dated latency statement in this cluster — "Hearing → speech-to-text → decision → text-to-speech is a full cognitive cycle (seconds, not milliseconds)" — which sits above the best historical number, a wiki recap of the 22 July 2024 dev stream reporting average delay cut from ~900 ms–1 s to "mostly 700 ms or lower" for both twins (T4, VOD linked); the widely repeated "1–3 seconds" figure is an unmeasured community inference and should not be reported as measured. No source at any tier names the STT engine Neuro actually uses: Whisper/faster-whisper appears only in clone projects (kimjammer/Neuro via RealtimeSTT) and a live search pass in this session showed search summaries still feeding that clone stack back as if it were Neuro's, so the engine must be reported as unknown. Turn-taking is otherwise documented only at SDK level and is well dated: actions/force gained a four-level priority on 17 Dec 2025 where "critical" interrupts her speech outright, speech_finished with isFinal marks the true end of an utterance (20 Aug 2026), and the voice channel exposes voice/speaking for push-to-talk keying and voice/cancelled for discarding buffered audio when she is interrupted. Everything about collab audio outside games remains T5 or worse: the Feb 2023 "interruption bug fixed in two days" story (Miyune 6 Feb, Camila 8 Feb 2023) is uncited wiki narrative, the "short complete sentences so the model doesn't guess how much time it has" rationale traces to an uncited EOS-token fan theory on the Virtual YouTuber wiki rather than to Vedal, and nothing names how Discord collab-partner audio reaches his stack — the closest official evidence being VOICE_CHAT.md's "voice-only clients" section, which says the same protocol can drive "Discord-like voice interfaces" with no game attached.

## Summary B (skeptic)
The only tier-1/2 evidence in this cluster is the official SDK material, and it is unusually strong because Vedal987 wrote it himself: API/VOICE_CHAT.md (single commit 6b79780, "Add voice chat support", 2026-08-19, corroborated by the CHANGELOG entry for the same date) specifies the voice side-channel as a second WebSocket carrying 48 kHz mono Float32 LE PCM, with per-speaker streams tapped before mixing, speakers registered as {id, name}, and an explicit audio-flow diagram "game VC (per-player streams) → server → STT (attributed) → Neuro" — so speaker attribution is supplied by the game's display name and server-side STT is confirmed, with no diarization anywhere in the spec. Turn-taking is likewise documented at T1/T2 only for the SDK loop: Vedal stated on 22 Feb 2025 (neuro-sdk discussion #58) that while she is deciding "she can only process one thing at once" and incoming context "will be merged after she is finished making her decision", while the CHANGELOG adds a force `priority` field (17 Dec 2025) whose "critical" level interrupts her speech mid-utterance, a `speech_finished`/`isFinal` turn-flow message (20 Aug 2026), a ~20 s server-side action/result timeout (21 Aug 2026) and a `voice/cancelled` event for interrupted speech. Everything else in this cluster is fan-wiki or community-inference: the ~700 ms average latency figure is a Neuro-sama Fandom recap of the 22 Jul 2024 dev stream (real page, real VOD link, garbled numbers, never checked against the VOD), the 6 Feb 2023 Miyune / 8 Feb 2023 Camila collab dates are corroborated by independent VOD uploads but the "interruption bug fixed in two days" framing and every architectural inference drawn from it are uncited wiki wording. No source, at any tier, names the STT engine Neuro actually uses — the only named engines (faster-whisper tiny.en via RealtimeSTT) come from the kimjammer/Neuro clone and must never be carried over — and no source describes how Vedal routes Discord collab audio into his stack; the closest official artifact is VOICE_CHAT.md's "Voice-only clients" section, which documents a voice-socket-only client "useful for building Discord-like voice interfaces", not a statement about what Vedal runs. The "short complete sentences in voice chat" design rationale is not a Vedal statement at all: it is a paraphrase of an uncited fan-theory passage about withheld EOS tokens in the Virtual YouTuber wiki's Trivia>System section. Date discipline matters here: every quantitative latency figure predates the Mar–Jun 2026 rewrite (which Vedal said explicitly targets "lower latency") and the May 2026 Threadripper/RTX PRO 6000 server, and Vedal's own doc warns the full hear→STT→decide→TTS cycle is "seconds, not milliseconds", so none of the 700 ms / 1–3 s numbers can be reported as current for 2026.

## Contradictions resolved
- Contradiction 1 (turn latency, 700 ms vs 1–3 s vs 'low latency'): resolved as different circuits and different dates, not a real conflict. The ~900 ms–1 s → '700 ms or lower' figure is a dated 22 Jul 2024 dev-stream recap (T4) about conversational response delay for both twins; the '1–3 s' figure is an undated community inference with no measurement behind it (T5); and Vedal's own Aug 2026 spec (T1) says the in-game voice-chat loop — hear → STT → decide → TTS — is 'a full cognitive cycle (seconds, not milliseconds)'. Report it as: text/chat turn ≈700 ms as of mid-2024, voice-chat round trip on the order of seconds as of Aug 2026, no published post-2024 chat figure, and drop '1–3 s' as unsourced.
- Contradiction 2 (action-force concurrency: serial-with-queue vs parallel-with-merge): resolved from the primary source itself. Both quotes are Vedal's, same thread, same day (22 Feb 2025). He says her cognition is serial — 'Neuro can't think about two things at once', and context arriving mid-decision 'will be merged after she is finished making her decision' — while the parallel handling of two simultaneous action/forces is prefaced with 'I really don't think you should do this' and 'this is untested'. So: serial decision step is the stated behaviour; parallel-force-with-merge is unshipped/untested design intent. The SDK's own SPECIFICATION warning that a second force in flight 'will cause problems' agrees with the serial reading. Separately, the Dec 2025 force-priority levels show that her speech is pre-emptible ('critical' interrupts her) even though her decision step is not.
- Contradiction 5 (first collab date, 6 Feb vs 22 Feb 2023): resolved in favour of 6 February 2023. I read the Virtual YouTuber wiki History section live: 'On 6 February, Neuro held her first collab stream with Miyune ... This issues was remedied for her collab with Camila on 8 February', sitting between cited entries for her 25 Jan 2023 return from the ban and her 20 Feb 2023 200k-follower milestone, which leaves no room for a 22 Feb first collab (the 22 Feb date in angle 09 most likely refers to a later Miyune appearance). Caveat: the 'remedied in two days' sentence itself carries no citation, so the two-day STT-fix story stays T5 even though the dates are now settled.
- Clone-contamination flag 4 (Whisper as Neuro's STT): reconfirmed as contamination, with fresh evidence. Vedal's own voice-chat spec names no STT vendor or model anywhere — it only says the server performs attributed STT — and a live search this session returned faster-whisper/RealtimeSTT-based answers that trace to kimjammer/Neuro. Any statement that Neuro 'uses Whisper' must be refused.
- #1 Turn latency (700ms vs 1-3s vs 'low latency'): RESOLVED as a measurement-point and date problem, not a factual conflict. The ~700 ms figure is a dated (22 Jul 2024) fan-wiki recap of a dev stream and describes average response delay for Neuro and Evil; the '1-3 s' figure is the lin-guanguo author's own admitted back-inference with no citation (I verified the page carries no source for it); and Vedal's own VOICE_CHAT.md (19 Aug 2026) describes the in-game voice-chat path as a full hear→STT→decide→TTS cycle taking 'seconds, not milliseconds'. Report: one dated 2024 wiki figure (~700 ms, measurement point undefined), one Vedal-stated 2024 delta (+400 ms as the price of more 'thinking'), one Vedal-written 2026 qualitative statement ('seconds') for the VC path specifically, and no current post-rewrite number at all. Do not present 1-3 s as a fact.
- #2 Action-force concurrency: RESOLVED as three statements about three different things, all from the same Vedal987 thread plus the spec. (a) SPECIFICATION.md: a game should not have two action forces in flight. (b) Vedal, 22 Feb 2025: if you do, 'she would independently and simultaneously process both requests at once and the two states should be merged back afterwards' — explicitly prefaced 'this is untested' and 'I really don't think you should do this', so it is intended, unverified behaviour, not a described implementation. (c) Vedal, same day: context arriving mid-decision is queued and 'merged after she is finished making her decision' — this is stated flatly and is about context, not forces. Serial-with-queue (context) and parallel-with-merge (two forces) are not describing the same mechanism. The 17 Dec 2025 force `priority` field adds a fourth, separate axis: pre-empting her speech output, up to 'critical' which interrupts mid-utterance.

Note separately that 'Camila' appears twice in this corpus with different meanings: the human VTuber Camila (8 Feb 2023 collab) and a later Vedal-built AI parody of her — do not merge them.

## New facts surfaced by verifiers
- [T1] (2026-08-19) Vedal's voice-chat spec states the full voice loop's cost in his own words: "Hearing → speech-to-text → decision → text-to-speech is a full cognitive cycle (seconds, not milliseconds), so treat her VC participation like a human player's." This is the only 2026-dated latency statement found anywhere. — https://raw.githubusercontent.com/VedalAI/neuro-sdk/main/API/VOICE_CHAT.md
- [T1] (2026-08-19) Voice chat rides a second, separate websocket at /game/<name>/voice; the main /game socket stays JSON-only so "the audio hot path" cannot block action/result traffic. The voice socket carries no identifier — the server pairs it with the main connection of the same game name. — https://raw.githubusercontent.com/VedalAI/neuro-sdk/main/API/VOICE_CHAT.md
- [T1] (2026-08-19) Upstream binary frame layout is documented exactly: offset 0 uint8 protocol version (1), offset 1 uint8 flags (reserved 0), offset 2 uint16 speaker id little-endian, offset 4+ Float32 PCM at 48 kHz mono; downstream is headerless PCM in the same format. Recommended frame 20 ms (960 samples / 3840 bytes), 10–100 ms acceptable; 192 KB/s per actively talking speaker, "fine for localhost/LAN". — https://raw.githubusercontent.com/VedalAI/neuro-sdk/main/API/VOICE_CHAT.md
- [T1] (2026-08-19) Endpointing/VAD is handled on Neuro's side: games are told to send audio only while a player is transmitting and that "the server handles trailing silence itself"; the server also drops malformed frames, frames for unknown speakers, and audio beyond internal buffer caps. — https://raw.githubusercontent.com/VedalAI/neuro-sdk/main/API/VOICE_CHAT.md
